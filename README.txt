2. Untuk foto profil, buka file `index.html`, cari `id="profileImg"` dan ganti bagian placeholder dengan:
   `<img id="profileImg" src="foto-kamu.jpg" alt="Foto profil Gangsar Wijaya" style="display:block">`
   lalu taruh `foto-kamu.jpg` di folder yang sama.
3. Ganti email, GitHub, Instagram, skill, dan proyek sesuai data asli kamu.
